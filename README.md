# Altoque

Aplicación móvil desarrollada con Flutter orientada a brindar apoyo en situaciones de emergencia. Permite facilitar la comunicación y compartir información relevante cuando una persona necesita asistencia inmediata.

## Funciones principales

- Gestión de contactos de emergencia.
- Acceso rápido a números de emergencia.
- Obtención y envío de la ubicación del usuario.

## Tecnologías utilizadas

- Flutter
- Dart
- Firebase
- Firestore
